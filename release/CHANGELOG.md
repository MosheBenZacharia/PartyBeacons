# 1.2.0

* Markers are now hidden in battlegrounds by default. Turn them back on with the new options panel checkbox or `/pb bg on`.

# 1.1.0

* New setting: maximum distance for edge indicators (default 500 yards, 0 = no limit). Options panel slider and `/pb maxdist`.

# 1.0.0

Initial release for WoW Forever.

* Class marker above each party member's nameplate
* Screen-edge indicator with distance for members out of view
* Per-character on/off and an options panel
